# План — ШЛИФ · Lab Console

Фронтенд лабораторной консоли для ML-классификации руд по панорамным микрофотографиям полированных шлифов (хакатон Норникель «СКАЖИ МНЕ КТО ТВОЙ ШЛИФ»).

**Стек:** Next.js 14 (App Router) + TypeScript + Tailwind v3.
**Архитектура:** Feature-Sliced Design (FSD). `app/` — тонкий роутинг Next (реэкспорт view). Слои в `src/`: `shared → entities → features → widgets → views`, импорты строго вниз, публичный API каждого слайса через `index.ts`. Алиас `@/* → ./src/*`.

```
app/                 роутинг Next (layout, page→view, globals.css)
src/
  shared/ui/spinner
  entities/  phase · sample · analysis        (типы, мок-данные, конфиг фаз/шагов)
  features/  upload-sample · analyze-sample · export-report
  widgets/   navbar · slide-viewer · metrics-panel · sample-queue · expert-bar
  views/     lab-console                       (композиция со стейтом)
```

**Приоритет:** сначала Lab Console (рабочий интерфейс), лендинг — позже.

Легенда: `[x]` сделано · `[~]` частично / заглушка · `[ ]` не начато.

### Что сделано сейчас (итог)
Рабочий прототип Lab Console: навбар, очередь из 3 образцов, интерактивный вьюер (маска фаз + heatmap + зум/пан + слои + прозрачность), панель метрик с вердиктом, заключением и экспортом CSV/HTML-отчёта, заглушка экспертного режима. Вся логика классификации соответствует правилам ТЗ, данные — детерминированный мок под замену реальным ML-API.

### Ближайшие шаги
1. `/design-login` → импорт `.dc.html` и подгонка верстки под эталон (действие пользователя).
2. Контракт API и замена мока на реальный бэкенд (upload → инференс → маска/метрики).
3. Пиксельная маска с бэкенда вместо кругов-заглушек во вьюере.
4. Инструмент ручной правки маски (кисть/лассо) в экспертном режиме.
