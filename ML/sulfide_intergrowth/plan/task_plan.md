## Decisions Made
- Двухступенчатая схема: (A) сегментация сульфидов U-Net, обученный на псевдо-масках
  из классической фотометрической сегментации (illumination-corrected luminance +
  hysteresis threshold, БЕЗ заливки дыр — дыры = замещение, это сигнал);
  (B) тайловый классификатор ConvNeXt (обычные vs тонкие) с метками от папки слайда.
- F1 меряется на уровне снимка (soft-vote тайлов), StratifiedGroupKFold по слайду
  (нет утечки), порог подбирается по OOF. Это единственная честная метрика — как в
  ML/intergrowth_seg (см. его README).
- Панорама: sliding window сегментера (full-res маска) + скользящая карта p_fine
  классификатора → покраска сульфидных пикселей.
- Тальк: не трогаем (тёмный → уходит в фон сегментации автоматически).
- Литературная база: Pérez-Barnuevo 2013/2018 (Min.Eng.) — тип срастания как
  текстурный класс; тайловый CNN-подход (transfer learning ImageNet) — из
  ML/intergrowth README. V100-32GB: convnext_small@448 b24 подтверждён.
