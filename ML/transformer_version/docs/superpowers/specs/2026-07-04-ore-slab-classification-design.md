# Дизайн: Классификация руд по OM-изображениям полированных шлифов

**Дата:** 2026-07-04
**Статус:** утверждён (вариант A — модульный «геологический» пайплайн)
**Данные:** `Задача 3. Скажи мне, кто твой шлиф/`

## 1. Задача

По изображению полированного шлифа (отражённый свет, включая панорамы до ~14k×11k px) система должна:

1. Сегментировать фазы: сульфиды / серая рудная фаза (магнетит) / нерудная матрица / тальк / фон-дефекты.
2. Классифицировать сульфидные зёрна по типу срастания: **обычные** (крупные, изолированные, минимальное замещение) vs **тонкие** (значительно замещённые нерудной фазой).
3. Оценить долю талька (оталькование).
4. Выдать сорт руды по экспертному правилу:
   - тальк > 10% → **оталькованная**;
   - иначе, тонкие срастания преобладают (> T, старт ~50%) → **труднообогатимая (тонкая)**;
   - иначе → **рядовая**.
5. Выдать интерпретируемые артефакты: цветной оверлей (зелёный = обычные срастания, красный = тонкие, синий = тальк), таблицу метрик (CSV), текстовый вердикт, карту неопределённости.

Ключевые требования: геологическая логика (не только метрики сегментации), устойчивость к вариациям съёмки, интерпретируемость, дообучаемость (transfer learning), автоматическая предобработка, пиксельная сегментация с сохранением морфологии.

## 3. Предобработка (единая для train/inference)

1. **Цветовая нормализация:** Lab; percentile-нормализация L; подавление колор-каста центрированием a/b по фону нерудной матрицы (не по всему кадру — иначе снимки с большим количеством сульфидов смещаются).
2. **Шумоподавление:** лёгкий bilateral/NLM на инференсе при необходимости; в обучении вместо этого шумовые аугментации.
3. **CLAHE** по L, консервативный clip limit.
4. **Артефакты шлифовки** (царапины, пыль, выколы): не удаляются на входе; устойчивость через аугментации (синтетические царапины/блики) + морфологический пост-фильтр мелких ложных срабатываний.
5. **Панорамы:** тайлы 1024×1024, перекрытие 25%, блендинг предсказаний по весу расстояния от края тайла; масштаб (µm/px) из увеличения в имени файла/метаданных.
6. **Аугментации против domain shift:** Lab color jitter, гамма, blur/sharpen, случайный сдвиг white balance.

## 4. Сегментация фаз

### 4.1 Классы

0 нерудная матрица · 1 сульфиды (единым классом) · 2 серая рудная фаза (магнетит и пр.) · 3 тальк/оталькование · 4 фон/дефекты. Разделение сульфидов по видам не делаем (YAGNI; LumenStone-предобучение позволяет добавить позже).

### 4.2 Модель

- Основная: **SegFormer-B2** (текстурно-контекстные признаки нужны для талька — тёмный пиксель без контекста неотличим от матрицы; трансформер устойчивее к domain shift; удобен для тайлового инференса). Fallback при слабой GPU: DeepLabv3+ (ResNet-50).
- Вход 1024×1024; выход — 5-канальный softmax + **карта неопределённости** (энтропия) для геолога и active learning.

### 4.3 Обучение (3 стадии)

1. **Stage 1:** предобучение на LumenStone S1+S2 (классы смаплены в наши 5), сильные цветовые аугментации.
2. **Stage 2:** дообучение на своих данных: маски талька (42) + псевдометки сульфидов/серой/матрицы (порог в Lab с confidence-отступом; неуверенные пиксели исключаются из лосса). Loss: Dice + weighted CE (тальк редкий).
3. **Stage 3:** self-training на всех ~1180 снимках; метки папок как sanity-фильтр (снимок из «оталькованных» с 0% талька по модели → на ручной просмотр, не в псевдометки). 2–3 итерации.

**Валидация:** сплит по шлифам (номер образца), не по снимкам; обязательный кросс-доменный тест ч1↔ч2.

## 5. Зёренный анализ срастаний

1. Связные компоненты класса «сульфид» + морфологическое замыкание (несколько px), минимальная площадь в µm².
2. Оболочка агрегата (convex/alpha-hull) = площадь зерна без замещения.
3. Признаки на зерно: `replacement_ratio` (нерудная+серая фаза внутри оболочки / площадь оболочки), `fragmentation` (число фрагментов), `boundary_complexity` (периметр / периметр эквивалентного круга), `size` (µm²), `contact_with_gray` (доля границы с магнетитом).
4. Классификатор «обычное/тонкое»: старт — пороговое правило на `replacement_ratio` + `size` (калибровка по совпадению image-level агрегата с метками папок); при нехватке точности — gradient boosting на тех же признаках (feature importance + per-grain таблица сохраняют интерпретируемость). Идейная база — минераллургические индексы Pérez-Barnuevo (Minerals Eng. 52, 2013), вычисляемые на DL-масках.

## 6. Экспертное правило и выходы

- Правило из §1.4; пороги (10%, T) — в YAML-конфиге, не в коде/весах.
- Доли — по площадям с учётом масштаба; для панорам дополнительно карта локальных долей по сетке (неоднородность шлифа).
- Выходы: оверлей (зелёный/красный/синий/серый, полупрозрачный), карта неопределённости, CSV-метрики (общая доля сульфидов, доли по типам срастаний, доля талька, гранулометрия, per-grain таблица), текстовый вердикт с указанием сработавшего правила.

## 7. Метрики приёмки и стресс-тесты

- Тальк: MAE доли ≤ 3% против экспертных масок.
- Срастания: F1 ≥ 0.90 на валидационной выборке зёрен (~200–300 зёрен, одноразовая разметка геологом).
- Сорт: accuracy на hold-out шлифах против меток папок.
- Стресс: кросс-домен ч1↔ч2; панорама ≤ 5 мин без артефактов на швах; снимки с царапинами.
- Fail-safe: >30% пикселей с высокой неопределённостью или аномальная доля фона → флаг «требует проверки геологом» вместо тихой классификации.

## 8. Адаптация к новым данным

Новое оборудование/руда: предобработка → карта неопределённости → доразметка 10–20 снимков (конвертер синих контуров переиспользуется) → fine-tune Stage 2 с малым lr. Версионирование весов и конфигов.
