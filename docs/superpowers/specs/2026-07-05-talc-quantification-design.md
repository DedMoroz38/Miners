# Дизайн: Количественная оценка талька на панорамных OM-снимках (±3%)

**Дата:** 2026-07-05
**Статус:** черновик на ревью
**Родительский спек:** `ML/transformer_version/docs/superpowers/specs/2026-07-04-ore-slab-classification-design.md` (§7: «Тальк: MAE доли ≤ 3%»)
**Жёсткое требование:** ошибка оценки доли талька ≤ ±3 п.п. относительно экспертной разметки.

---

## 1. Постановка

Вход — панорамный OM-снимок полированного шлифа (до ~13712×10798 px, тёмный
нейтральный профиль, швы сшивки). Выход:

1. синяя полупрозрачная маска талька поверх исходника;
2. доля талька в % от **валидной площади шлифа** (без фона/смолы), плюс
   абсолютная площадь в µm² при известном масштабе;
3. побочно — карта светлых сульфидных фаз (нужна для требования «выделение
   сульфидов» и для контракта с блоком слияния).

Тальк — тёмная рассеянная фаза в нерудной матрице: сигнал текстурный
(«тёмное на тёмном»), а не яркостный. Это задача **семантической сегментации
stuff-класса + квантификации**, а не instance-детекции: текущий YOLO-seg
бейзлайн упирается в mask mAP50 ≈ 0.28 (`first_segmentation_attempt`,
epoch 215) — формулировка неверна, а не гиперпараметры.

## 2. Аудит данных (сделан, ключевые факты)

| Источник | Объём | Факт |
|---|---|---|
| `first_labling_attempt/yolo_seg` | 42 изображения, 205 полигонов | перерисованная руками разметка синих линий; средняя доля талька **29.3%**, разброс 4.7–63.6% |
| `talcification_zones/` (ч1) | 42 оригинала с синей линией эксперта | линии часто **незамкнутые** (граница зоны, уходящая за кадр) |
| Автозаливка линий (`orenet/talc_masks.py`) | — | расходится с ручными полигонами в среднем на **16.6 п.п.** (до 59 п.п.): автозамыкание не понимает открытые контуры (даёт 0% там, где эксперт обвёл полкадра). Ручные полигоны — верная интерпретация; автозаливка — сломанная |
| ч1 поля (Canon 2272×1704, ×5/×10 в имени) | 43+68+68 | оливковый колор-каст |
| ч2 поля (4160×2768 и др.) | 87+497+418 | нейтральный профиль; только метки папок |
| Панорамы | 14 шт., до 148 Мп | сильно недоэкспонированы, швы; **µm/px не зафиксирован** |
| Канонический препроцессинг (`preprocess_talc` = сульфидный `preprocess_image`) | — | якорная нормализация только L-канала: **колор-каст (a/b) не выравнивает** — оливковые поля остаются оливковыми, панорамы серыми (проверено визуально) |

Два вывода, определяющих весь дизайн:

* **±3 п.п. недостижимы без замороженного эталона.** Две существующие
  интерпретации одной и той же экспертной разметки расходятся на 16.6 п.п. —
  в 5 раз больше допуска. Сначала фиксируем GT, потом меряем модель.
* **Главный разрыв train→inference — хроматический домен и экспозиция**, а
  существующая нормализация закрывает его только по яркости.

## 3. Эталон и метрика (Фаза 0 — блокирует всё остальное)

1. **Аудит 42 масок.** Скрипт собирает триптихи «оригинал | синяя линия |
   ручная маска»; человек за ~1 час подтверждает/правит грубые расхождения в
   Label Studio (особенно открытые контуры). Результат — **frozen GT v1**
   (хэш датасета в логе эксперимента).
2. **Конвенция площади — зонная**, как рисует эксперт: мелкие включения внутри
   обведённой зоны талька входят в её площадь. Модель обучается и оценивается
   в одной конвенции; спор «пиксель vs зона» снят.
3. **Метрика приёмки:** по-изображению |Δ доли| на grouped-CV;
   **MAE ≤ 3 п.п.** (обязательно), P90 ≤ 3 п.п. (цель), |bias| ≤ 0.5 п.п.,
   ни одного |Δ| > 6 п.п. Доля считается от валидной площади (класс
   «фон/смола» исключён из знаменателя).
4. **Контроль ложноположительных:** на снимках рядовых/труднообогатимых сортов
   (ч2, ~915 шт.) предсказанная доля талька — распределение с медианой ~0 и
   P95 ≤ 3 п.п. Иначе ±3% «выполняется» только на оталькованных шлифах, что
   бессмысленно для продукта.

## 4. Архитектура (два трека в одном каркасе, решает CV)

### Трек A — основной: SegFormer-B2/B3, 5 классов

Переиспользует готовый каркас `transformer_version/src/orenet` (model, losses,
dataset, engine): MiT-B2 (ADE20k-претрен) → при запасе по CV-метрике — B3
(V100-32GB тянет B3 @768, bs 8, AMP). Классы: матрица / сульфид / серая фаза /
тальк / фон; супервизия сульфидов и серой фазы бесплатная (GMM-псевдометки,
`pseudolabels.py`), она же затачивает границу «тальк ↔ тёмная матрица» и даёт
карту сульфидов и валидную площадь.

### Трек B — претендент: frozen DINOv2 ViT-B/14 + лёгкий декодер

Замороженный self-supervised бэкбон + обучаемый декодер (linear/UPerNet-lite).
На 42 изображениях иммунен к переобучению, текстурные признаки сильные,
устойчивее к цветовому сдвигу; обучается за ~2 ч/фолд. Дешёвая страховка с
высоким потолком.

**Правило выбора:** grouped-CV talc-MAE; при разнице < 0.5 п.п. — ансамбль
A+B (усреднение вероятностей). Никаких «нравится/не нравится» — только метрика.

### Почему не YOLO/instance

Тальк — аморфные зоны («stuff»), декомпозиция на инстансы + OR-склейка тайлов
добавляет систематическую ошибку площади; softmax-вероятности семантической
модели напрямую питают слой квантификации (§6).

## 5. Данные и обучение (стадии)

0. **Фаза 0** — frozen GT (§3).
1. **Претрен:** LumenStone S1+S2 (+P1, если качество меток ок) с маппингом
   классов в наши 5; сильные цветовые аугментации. (Открытый датасет MISIS по
   Cu-Ni сульфидным рудам, полированные шлифы, пиксельные маски.)
2. **Fine-tune:** 42 GT-маски талька (патчи 512–768, rare-class sampling +
   copy-paste банка талька — уже реализовано в `dataset.py`) + GMM-псевдометки
   остальных классов на ~1180 полях; неуверенные пиксели = ignore(255).
3. **Self-training (2 раунда максимум):** учитель = ансамбль фолдов →
   псевдометки на ч2-оталькованных (87) и тайлах панорам; фильтры: только
   высокоуверенные пиксели, вес псевдометок 0.5, sanity по меткам папок
   (не-тальковый сорт с >10% предсказанного талька → в карантин на просмотр,
   не в обучение).

### Доменная робастность (закрывает разрыв поля→панорама)

* **Препроцессинг per-tile, единый train/inference — переиспользование:**
  `preprocess_talc` (якорная L-нормализация + median3, байт-в-байт сульфидный
  профиль) **плюс** нейтрализация каста a/b по тёмной матрице — уже
  реализована в `orenet/preprocess.py` (шаг 2), берём только её (без CLAHE и
  percentile-stretch, чтобы не трогать абсолютную рефлектность). Это
  композиция двух существующих реализаций; замена оправдана доказанным
  остаточным хроматическим разрывом (п. «крайняя необходимость» ТЗ).
* **Аугментации:** Lab-джиттер a/b (±15), яркость/контраст/гамма, blur/шум/
  JPEG; с p=0.3 — полное обесцвечивание (L→RGB), чтобы модель не могла
  опираться на оттенок.
* **FDA-стилизация:** подмена низкочастотной амплитуды спектра обучающего
  тайла спектром случайного тайла панорамы (Fourier Domain Adaptation) —
  дёшево переносит «панорамный вид» в обучение без меток.
* **Масштаб:** парсим ×5/×10/×20 из имён, ресемпл к каноническому µm/px
  (эквивалент ×10) + скейл-джиттер ±20%. **Открытый вопрос владельцу данных:
  µm/px панорам** — до ответа страхуемся мультимасштабным TTA (×0.8/1/1.25).

## 6. Слой квантификации — механика ±3%

Сегментация даёт маску; долю даёт отдельный, калиброванный оценщик:

1. **Лосс:** Dice + Focal-Tversky + weighted CE (готовый `DiceFocalTversky`)
   **+ area-consistency член** λ·|Σp_talc − Σy_talc|/N_valid (λ≈0.1) на
   GT-кропах — прямо штрафует смещение доли. Помним про volume bias
   soft-Dice (Bertels et al., 2022): вес CE держим ≥ региональных, финальную
   несмещённость обеспечивает пост-калибровка, а не лосс.
2. **Оценка доли = Σ калиброванных p(тальк) / N_valid** (probabilistic
   classify-and-count), а не подсчёт argmax-пикселей: мягкая сумма менее
   чувствительна к порогу и лучше калибруется.
3. **Калибровка (только на out-of-fold предсказаниях, ≤3 параметров):**
   temperature scaling талькового канала → квантификационная поправка
   (adjusted count (CC−FPR)/(TPR−FPR) по Forman, либо робастная линейная
   поправка Theil–Sen pred→GT — выбираем по CV) → контроль |bias| < 0.5 п.п.
4. **Ансамбль 5 фолдов + TTA** (флипы, ±масштаб) — усреднение вероятностей
   снижает дисперсию и стабилизирует калибровку.
5. **Порог для визуальной маски** подбирается per-image так, чтобы площадь
   бинарной маски совпала с калиброванной мягкой оценкой — оверлей и число в
   отчёте никогда не противоречат друг другу.

## 7. Инференс панорамы

1. Валидная площадь: класс «фон» ∪ тёмная кайма смолы → вне знаменателя.
2. Тайлы 1024 px в каноническом масштабе, перекрытие 50%, **склейка
   вероятностей косинусным окном** (заменяет OR-union из `talc_infer` —
   тот систематически завышает площадь на перекрытиях); геометрия сетки —
   переиспользуем `tiling.py`.
3. Пер-тайловый препроцессинг (§5); батчинг тайлов по 8–16.
   148 Мп ≈ 550 тайлов × (5 моделей × 2 TTA) ≈ 1–3 мин на V100 — в бюджете.
4. Выходы (контракт `merge_phases.py` сохранён): `talc_mask.png`,
   `talc.json` (доля + 95% CI по разбросу ансамбля, карта локальных долей
   по сетке, флаги), синий оверлей PNG, карта энтропии.
5. **Fail-safe:** доля в [8%, 12%] (около продуктового порога 10%) → флаг
   «на проверку геологу»; детектор доменного сдвига (величина каста до
   коррекции, разлёт якорей L) вне диапазона → флаг.

## 8. Валидация

* **Grouped 5–7-fold CV**, группы = шлиф (255037x-y → шлиф 255037x; DSCN — по
  кластерам последовательной нумерации: 3042–3066, 4695–4735, 4754–4755,
  5032, 5180–5186). Один шлиф никогда не в train и val одновременно.
* Отчёт: MAE, медиана, P90, max, signed bias, bootstrap-CI; всё по фолдам и
  пуллом.
* Кросс-домен: (а) не-тальковые папки ч2 → FP-контроль (§3.4); (б) тальковая
  папка ч2 → доля >10% у большинства; (в) все 14 панорам → визуальные оверлеи
  + чек-лист геолога (швы, кайма, крупные зоны).
* Абляции (каждая — по talc-MAE): претрен (LumenStone vs ADE-only), каст-
  нейтрализация, FDA, area-loss, шаги калибровки, размер ансамбля, A vs B
  vs A+B, self-training.
* Воспроизводимость по правилам репо: seed, Hydra-конфиги, хэш датасета,
  pip freeze в артефактах прогона.

## 9. Риски

| Риск | Митигация |
|---|---|
| Шум GT сопоставим с допуском | Фаза 0 (аудит), при сомнениях — адъюдикация экспертом худших 10 изображений; допуск меряется против frozen GT |
| µm/px панорам неизвестен | запрос владельцу данных; до ответа — скейл-джиттер в обучении + мультимасштабный TTA |
| Задавленные тени панорам (SNR) | экспозиционные аугментации + FDA; тест на «панорамизированной» валидации (train-тайлы, стилизованные под панораму): деградация MAE >1.5× → добавить histogram-matching вариант препроцессинга |
| Переобучение калибровки на 42 точках | только out-of-fold фит, ≤3 параметров, робастный Theil–Sen |
| Дрейф self-training | фильтры уверенности, вес 0.5, ≤2 раундов, абляция «с/без» |
| Швы сшивки | 50% перекрытие + косинусная склейка; визуальный тест на панораме 4 |

## 10. Бюджет compute (V100 32GB)

| Этап | Оценка |
|---|---|
| Претрен LumenStone (B2 @512, bs16, ~20k iter) | 4–6 ч |
| Fine-tune ×5 фолдов (B2 @768, bs8) | 6–10 ч × 5 (ночь×2) |
| Трек B (frozen DINOv2 + декодер) ×5 | ~2 ч × 5 |
| Self-training раунд | +50% к fine-tune |
| Полная матрица с абляциями | ~3–5 GPU-дней суммарно |

## 11. Вне скоупа

Интеграция в backend/frontend, merge-логика, переобучение сульфидного блока.
Контракты выходов (`talc.json`, `talc_mask.png`) сохранены, поэтому интеграция
сводится к замене вызова `talc_infer`.

## 12. Критерий приёмки дизайна

Дизайн считается выполненным, когда на frozen GT v1 grouped-CV даёт
MAE ≤ 3 п.п., |bias| ≤ 0.5 п.п., FP-контроль на не-тальковых сортах
P95 ≤ 3 п.п., и все 14 панорам проходят визуальный чек-лист геолога.
